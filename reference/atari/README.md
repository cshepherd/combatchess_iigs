# Atari original

Put the Combat Chess disk or program image here (for example
`combat_chess.atr` or `combat_chess.xex`). Image files in this
directory are ignored by git: the game is Avalon Hill's copyrighted
software and is not part of this repository.

Then run the capture session:

```
tools/atari_capture.sh reference/atari/combat_chess.atr boards
```

and follow `reference/notes/capture_session.md`.
